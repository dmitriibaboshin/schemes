# Schemes

Interactive architecture schemes, served with GitHub Pages.

| Scheme | What it shows | draw.io |
|---|---|---|
| [Hermes isolation topology](https://dmitriibaboshin.github.io/schemes/hermes-isolation/) | Hermes Agent on Kubernetes 1.36: runtimes (gVisor, runc, user namespaces), NetworkPolicies on every path, iron-proxy egress zones, model gateway and router, other model clients moving behind it, logging points, pod hardening and minimum versions | [file](hermes-isolation/hermes-isolation.drawio) · [open in diagrams.net](https://app.diagrams.net/#Uhttps%3A%2F%2Fraw.githubusercontent.com%2Fdmitriibaboshin%2Fschemes%2Fmain%2Fhermes-isolation%2Fhermes-isolation.drawio) |

Each scheme is a single self-contained HTML file with its fonts embedded, so it works offline too: download `index.html` from its folder and open it in a browser. The draw.io copy keeps the layout and the hover descriptions (as tooltips) but has no animation.
