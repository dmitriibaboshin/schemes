# Schemes

Interactive architecture schemes, served with GitHub Pages.

| Scheme | What it shows |
|---|---|
| [Hermes isolation topology](https://dmitriibaboshin.github.io/schemes/hermes-isolation/) | Hermes Agent on Kubernetes 1.36: runtimes (gVisor, runc, user namespaces), NetworkPolicies on every path, iron-proxy egress zones, pod hardening and minimum versions |

Each scheme is a single self-contained HTML file with its fonts embedded, so it works offline too: download `index.html` from its folder and open it in a browser.
